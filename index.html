01 / 06 · from scratch

Vector Search Engine

Search by meaning, with every index written by hand.

Exact search and an HNSW index in NumPy, no FAISS or hnswlib: per-layer graph, the paper's diversity-based neighbor selection, beam search, pickle-free persistence. Recall lands within 0.004 of hnswlib at identical settings.

0.98 recall@10 at 0.52 ms on 120k real sentence embeddings, 16.6× faster than single-thread exact search. Against a pure-Python HNSW on the same eval: 0.91 vs 0.62 recall@10, ~34× faster.

02 / 06 · agents

Energy Copilot (Text2SQL agent)

Ask about your home's electricity in plain language.

An 11-node LangGraph agent answering questions on household electricity use, cost and savings over smart-meter and NILM time series. The LLM fills a query plan, and code compiles it to parameterized SQL.

Every query passes a sqlglot guard, runs read-only and scoped to one home, and every number in an answer traces to a query result. Routes across 11 skills and 25 tools: skill hit@1 1.0, tool precision/recall 0.786 / 0.964 on a 28-case end-to-end set.

03 / 06 · research

autoresearch, with human gates

An AI agent runs LLM training experiments; a human reviews each round.

A fork of karpathy/autoresearch that replaces the overnight keep-if-lower loop with a three-round protocol at 1/4, 1/2 and full data, pausing for review after each round.

A change is kept only if it clears 2σ of measured seed noise. Runs stop on tokens instead of wall clock, so results reproduce on any GPU, and a sealed test shard measures how much the validation set was overfit.

03 About me

I grew up as a chess player. For years my evenings went to a board: calculating lines, studying openings and learning to lose gracefully. Chess taught me to think several moves ahead and to treat every mistake as something to study rather than hide.
